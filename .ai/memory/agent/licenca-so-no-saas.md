O Sofon/segtools hoje é um framework pessoal do dono, não um SaaS em produção. Até isso mudar, licença (AGPL, GPL ou qualquer outra) NÃO pesa na escolha de ferramenta, biblioteca ou motor: usar direto o que for melhor tecnicamente (ex.: ParadeDB, Typesense). Licença só volta a ser critério se o projeto for para produção como SaaS — aí reavaliamos.

**Why:** dono, 01/10/2026: "de início não somos SaaS, é um framework meu apenas; se chegarmos a ir para prod como SaaS aí repensamos. Antes disso desconsidere qualquer tipo de licenciamento".

**How to apply:** em pesquisa e decisão técnica, não descartar nem rebaixar opção por licença; no máximo uma nota "rever se virar SaaS". Complementa [[licenca-nao-barra-ideia]].
