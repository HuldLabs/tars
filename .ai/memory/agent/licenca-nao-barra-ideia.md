Portar, no segtools, é ler a lógica de um projeto (qualquer licença, até "todos os direitos reservados"), entender como é feito e reimplementar do nosso jeito — nunca copiar código, prompt ou texto literal. Licença não é motivo para descartar uma referência; algoritmo e ideia se aproveitam.

**Why:** 01/10 o dono corrigiu: eu descartei o BugSense AI ("não dá para portar") por ser All Rights Reserved.

**How to apply:** em spike/benchmark, classificar referência por valor técnico, não por licença; a coluna de licença só indica se dá para copiar trecho literal (MIT/Apache) ou se é só inspiração. Ver [[estado-da-arte-antes-de-construir]].
